# App_perdidas

Apps de hidráulica de tuberías y canales para calculadoras gráficas (curso de Fluidos, UCR).

| Carpeta | Calculadora | Contenido |
|---|---|---|
| [TI-84 Plus CE](TI-84%20Plus%20CE/) | TI-84 Plus CE | PERDIDAS (pérdidas en tuberías) y FLUJOS (arrastre, vertedores, canales); v2.1 |
| [TI-Nspire CX II CAS](TI-Nspire%20CX%20II%20CAS/) | TI-Nspire CX II / CX II CAS | Mismas funciones en un solo documento Lua `PerdidasFlujos.tns`, sin jailbreak; 1.0 Nspire (basada en la v2.1) |

Más calculadoras se agregarán como carpetas hermanas. Ver el `README_es.md` de cada carpeta.
