# App_perdidas

Apps de hidráulica de tuberías y canales para calculadoras gráficas (curso de Fluidos, UCR).

| Carpeta | Calculadora | Contenido |
|---|---|---|
| [TI-84 Plus CE](TI-84%20Plus%20CE/) | TI-84 Plus CE | PERDIDAS (pérdidas en tuberías) y FLUJOS (arrastre, vertedores, canales); v2.1 |
| [TI-Nspire CX II CAS](TI-Nspire%20CX%20II%20CAS/) | TI-Nspire CX II / CX II CAS | Mismas funciones en un solo documento Lua `PerdidasFlujos.tns`, sin jailbreak; 1.2 Nspire (basada en la v2.1; agrega estática y dinámica de fluidos, tres tanques y las Modificaciones JV: bomba en la línea, «Mi programa original» y redondeo a 3 decimales) |

**Estado: versión final.** TI-Nspire 1.0 y TI-84 v2.1, ambas probadas en la calculadora real.
Los archivos para instalar están en la carpeta `instalacion/` de cada calculadora y en la
[release «final»](https://github.com/adrianix360/App_perdidas/releases/tag/final).

Más calculadoras se agregarán como carpetas hermanas. Ver el `README_es.md` de cada carpeta.
